# WP Deep Reset Guard

管理者専用の WordPress サイト初期化・完全クリーンアッププラグインです。

テーマ・プラグイン・アップロードファイル・データベースを安全に削除し、WordPress 標準テーマだけを残した初期状態に戻します。FTP から見ても不要なフォルダやファイルが残らないよう、サーバー上から実際に削除します。

> **⚠ 警告**: このプラグインはサイトのデータを**完全に削除**します。実行前に必ずバックアップを取得してください。

---

## 特徴

- **テーマ削除** — WordPress 標準テーマ（Twenty 系）以外をフォルダごと完全削除
- **プラグイン削除** — このプラグイン自身を除く全プラグインをフォルダごと完全削除
- **uploads 削除** — `wp-content/uploads/` 配下の画像・PDF・動画・年月フォルダを再帰削除
- **追加フォルダ削除** — `mu-plugins` / `cache` / `upgrade` / `languages` を選択削除
- **データベース初期化** — WordPress テーブルの DROP または TRUNCATE
- **Dry-Run モード** — 削除せずに対象一覧だけを確認可能
- **AJAX バッチ処理** — 大量ファイルでもタイムアウトしにくい分割処理＋進捗バー表示

## 安全装置

このプラグインは不用意に実行できないよう、複数の安全装置を備えています。

| 安全装置 | 内容 |
|---|---|
| 権限チェック | `manage_options`（管理者）権限が必須 |
| マルチサイト禁止 | マルチサイト環境では動作しない |
| nonce 検証 | フォーム送信・AJAX の両方で検証 |
| 足し算チャレンジ | ランダムな計算問題に正解しないと実行不可（サーバー側再検証） |
| 確認テキスト入力 | `DELETE` または `完全に削除することを理解しました` を手入力 |
| 連打防止 | 5 秒間のレート制限 |
| パス検証 | `realpath` による正規化 + `wp-content` 配下限定 |
| シンボリックリンク保護 | シンボリックリンクは削除しない |
| 保護ファイル除外 | `wp-config.php` / `.env` / `.htaccess` 等は絶対に触れない |
| コア保護 | `wp-admin` / `wp-includes` には一切触れない |

## 動作要件

- WordPress 5.0 以上
- PHP 7.4 以上
- シングルサイト環境（マルチサイト非対応）

## インストール

### ZIP アップロード

1. このリポジトリの `wp-deep-reset-guard/` フォルダを ZIP 化する
2. WordPress 管理画面 → **プラグイン** → **新規追加** → **プラグインのアップロード**
3. ZIP ファイルを選択して「今すぐインストール」→「有効化」

### FTP / ファイルマネージャ

`wp-deep-reset-guard/` フォルダを `wp-content/plugins/` 直下にアップロードし、管理画面でプラグインを有効化してください。

## 使い方

1. 管理画面 → **ツール** → **⚠ サイト初期化** を開く
2. サイト情報と削除対象一覧が自動スキャンされて表示される
3. 削除したい項目にチェックを入れる
   - テーマ・プラグイン・uploads はデフォルトで選択済み
   - 追加フォルダ・データベースは**デフォルトで未選択**（危険なため）
4. **Dry-Run（テスト実行）** ボタンで何が削除されるかを確認
5. 本実行する場合:
   - 操作モードを「本実行」に切り替え
   - 足し算問題に正解する
   - 確認テキストを入力する
   - 「本実行（削除開始）」ボタンを押す
6. 処理ログと結果サマリーがリアルタイムで表示される

## ファイル構成

```
wp-deep-reset-guard/
├── wp-deep-reset-guard.php        # メインプラグインファイル
├── includes/
│   ├── class-wdrg-core.php        # コア（メニュー登録・AJAX処理）
│   ├── class-wdrg-scanner.php     # スキャン（対象一覧の生成）
│   ├── class-wdrg-executor.php    # 実行（ファイル・フォルダの削除）
│   ├── class-wdrg-database.php    # DB初期化（DROP / TRUNCATE）
│   ├── class-wdrg-logger.php      # ログ管理（ファイル＋メモリ）
│   └── class-wdrg-safety.php      # 安全装置（検証・チャレンジ）
├── assets/
│   ├── admin-style.css            # 管理画面CSS
│   └── admin-script.js            # 管理画面JS
└── templates/
    └── admin-page.php             # 管理画面テンプレート
```

## 注意事項

- **バックアップ必須** — 削除されたファイルやテーブルは復元できません
- **ユーザーテーブル** — `wp_users` / `wp_usermeta` を削除するとログインできなくなります
- **DB 初期化後** — WordPress の再インストールが必要になる場合があります
- **ログ** — 処理ログは `wp-content/wdrg-logs/` に保存されます
- **自己削除** — このプラグイン自身はデフォルトで削除対象から除外されます
